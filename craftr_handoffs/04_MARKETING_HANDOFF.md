# Craftr — Marketing Handoff

## Core marketing rule
Do not market the technology.
Market the transformation:

**"I described a product. AI built the real thing."**

Avoid:
- generative CAD jargon
- agent architecture explanations
- long technical feature lists

## Core message
Primary:
**Describe it. Build it. Order it.**

Alternatives:
- Turn ideas into hardware.
- Build physical products from a prompt.
- The easiest way to make hardware.
- Software lets anyone build software. Craftr does the same for physical products.

## Launch content format
Make short build videos.

Structure:
1. show prompt
2. show components selected
3. show block graph
4. show 3D model forming
5. show exploded view
6. show print
7. show assembly
8. show working device

The physical reveal is the hook.

## First demo ideas

### Demo 3 — Pomodoro cube

## Recurring social series
**Day X of asking AI to manufacture things that don't exist.**

Channels:
- X
- LinkedIn
- Reddit
- Hacker News / Show HN
- maker communities
- hardware Discords
- Product Hunt later

## Landing page structure
### Hero
What do you want to build?

Prompt box + live generated product.

### Proof
Show actual objects generated by Craftr.

### How it works
Prompt → Blocks → Model → Firmware → Order

### CTA
**Build something**

Avoid long explanations above the fold.

## Early-user acquisition
Target:
- indie hackers
- developers curious about hardware
- startup founders
- design students
- makers

Offer:
> Give us any small electronic product idea. We'll try to generate and fabricate it.

This gives Craftr both users and training/failure data.

## What to collect publicly
- number of product ideas generated
- number of successful builds
- number ordered
- time from prompt to physical object
- first-build success rate

These numbers become both marketing and fundraising proof.

## Marketplace marketing later
Creators should be able to publish products with:
- Remix
- Change with AI
- Order

Example:
"Make this smaller."
"Make it solar."
"Add Spotify controls."

This can turn Craftr into a creator ecosystem rather than only a tool.

## Brand feel
Craftr should feel:
- playful
- tactile
- smart
- accessible
- premium but not enterprise-heavy

The visual language should reinforce modular construction / Blocks without looking like a LEGO clone.
